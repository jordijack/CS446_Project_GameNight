3สร้างฐานข้อมูล Amazon DynamoDB

  1. ช่องค้นหาพิมพ์ DynamoDB → เมนูซ้าย Tables → Create table
  2. สร้างทั้งหมด 6 ตาราง ตามตารางด้านล่าง กรอกให้ตรงทุกตัวอักษร ช่องชนิดข้อมูลด้านขวาของ key เลือก String หรือ Number ตามตาราง
  3. ส่วน Table settings ใช้ Default settings (On-demand) แล้วคลิก Create table รอจนสถานะเป็น Active

6สร้าง REST endpoint Amazon API Gateway

  1. ช่องค้นหาพิมพ์ API Gateway → ที่การ์ด HTTP API คลิก Build
  2. คลิก Add integration → เลือก Lambda → Region us-east-1 → Lambda function เลือก gamenight-api
  3. API name พิมพ์ gamenight-http-api → Next
  4. หน้า Configure routes: Method เลือก ANY, Resource path พิมพ์ $default, Integration target gamenight-api → Next
  5. หน้า Stages ใช้ $default และ Auto-deploy เปิดไว้ → Next → Create
  6. คัดลอก Invoke URL (หน้าตา https://xxxxxxxxxx.execute-api.us-east-1.amazonaws.com) เก็บไว้
  7. ทดสอบ: เปิด <Invoke URL>/api/health ในเบราว์เซอร์ ต้องได้ {"ok":true}
ห้ามตั้ง CORS ใน API Gatewayเมนู CORS ของ HTTP API ให้ปล่อยว่าง โค้ด Express ตอบ CORS เองอยู่แล้ว ถ้าตั้งที่ API Gateway ด้วย ค่าจะทับกันจนหน้าเว็บเรียก API ไม่ได้

7ใส่ข้อมูลตัวอย่าง DynamoDB seed

Lambda gamenight-api มีโค้ด seed อยู่ในตัวแล้ว สั่งผ่านปุ่ม Test ได้เลย ไม่ต้องรันอะไรในเครื่อง

  1. Console → Lambda → gamenight-api → แท็บ Test
  2. เลือก Create new event → Event name seed → ช่อง Event JSON ลบของเดิมแล้ววางค่าด้านล่าง → Test
  3. กล่องผลลัพธ์สีเขียวต้องขึ้นข้อความ Seed เสร็จ ใส่ 24 เกม 12 แนวเกม 6 แพลตฟอร์ม 16 บริษัท และผู้ใช้ตัวอย่าง 2 คน
Event JSON
{ "seed": true }

กดซ้ำได้ ถ้าตารางมีเกมอยู่แล้วจะข้ามให้ ถ้าต้องการเขียนทับให้ใช้ { "seed": "force" } บัญชีตัวอย่างคือ demo@gamenight.test และ mai@gamenight.test รหัสผ่านอยู่ในไฟล์ aws-deploy/serverless/src/seed-data.ts บน GitHub

คนนอกสั่ง seed ไม่ได้request ที่มาจาก API Gateway ไม่มี key seed ที่ระดับบนสุด คำสั่งนี้จึงใช้ได้เฉพาะคนที่เข้า Lambda Console ได้

8โฮสต์หน้าเว็บ AWS Amplify

Amplify ดึงโค้ดจาก fork บน GitHub ไป build เอง (ใช้ไฟล์ amplify.yml ที่อยู่ใน repo) ทุกครั้งที่มีการแก้ใน branch main เว็บจะ deploy ใหม่อัตโนมัติ

8.1 ต่อ Amplify กับ GitHub

  1. ช่องค้นหาพิมพ์ Amplify → Create new app → เลือก GitHub → Next
  2. หน้าต่าง GitHub เด้งขึ้นมา → Authorize AWS Amplify → หน้า Install เลือก Only select repositories → เลือก fork ของตัวเอง → Install & Authorize
  3. Repository เลือก fork ของตัวเอง, Branch main
  4. ติ๊ก My app is a monorepo → Monorepo root directory พิมพ์ frontend → Next

8.2 ตั้งค่า build แล้ว deploy

  1. App name gamenight-web หน้านี้ควรขึ้นว่าพบไฟล์ amplify.yml แล้ว ไม่ต้องแก้คำสั่ง build
  2. เปิด Advanced settings → Environment variables → Add new
    Key
    VITE_API_URL
    Value
    Invoke URL จากขั้น 6 ต่อท้ายด้วย /api เช่น https://xxxxxxxxxx.execute-api.us-east-1.amazonaws.com/api
  3. ถ้ามีช่อง Service role ให้เลือก Use an existing service role → LabRole (Learner Lab สร้าง role ใหม่ไม่ได้) ถ้าไม่มี LabRole ในรายการให้เว้นว่าง เว็บแบบ static ไม่ต้องใช้ role
  4. Next → Save and deploy รอจนทั้ง 3 ขั้น Provision → Build → Deploy เป็นสีเขียว (ประมาณ 3–5 นาที)
  5. คัดลอก Domain (หน้าตา https://main.xxxxxxxx.amplifyapp.com) เก็บไว้
แก้หน้าเว็บภายหลังแก้ไฟล์ใน fork บน GitHub (กดรูปดินสอ → Commit changes) Amplify จะ build ใหม่เอง ถ้าเปลี่ยน VITE_API_URL ต้องกด Redeploy this version ในหน้า Deployments เพราะค่านี้ถูกใส่ลงไปตอน build
ถ้าต่อ GitHub ไม่ได้บางบัญชี Learner Lab อาจไม่ยอมให้ต่อ GitHub ให้ใช้ Deploy without Git แทน วิธีนี้ต้องมี Node.js 22 ในเครื่อง: clone repo → cd frontend → npm ci → ตั้ง VITE_API_URL → npm run build → zip ไฟล์ข้างใน dist (ไม่ใช่ตัวโฟลเดอร์) แล้วลากไปวางในหน้า Amplify

8.4 ใส่โดเมนกลับไปที่ Lambda

กลับไปที่ Lambda ทั้ง 2 ตัว → Configuration → Environment variables → แก้ SITE_URL เป็นโดเมน Amplify ลิงก์ในอีเมลแจ้งเตือนจะพาไปหน้าเกมได้

9ตั้งเวลาตรวจราคาทุกชั่วโมง Amazon EventBridge

  1. ช่องค้นหาพิมพ์ EventBridge → เมนูซ้าย Buses › Rules → Create rule
  2. Name gamenight-hourly, Event bus default, Rule type เลือก Schedule
  3. ถ้า Console เสนอให้ไปใช้ EventBridge Scheduler ให้เลือก Continue in EventBridge Rules
  4. Schedule pattern เลือก A schedule that runs at a regular rate → 1 Hours → Next
  5. Target: AWS service → Lambda function → Function gamenight-deals → Next → Next → Create rule

Console จะเพิ่มสิทธิ์ให้ EventBridge เรียก Lambda ตัวนี้ได้เอง ตรวจได้ที่ Lambda gamenight-deals → แผนภาพด้านบนต้องมีกล่อง EventBridge (CloudWatch Events) เป็น trigger

ภาพ Console: หน้า Rule gamenight-hourly ที่เห็น Schedule rate(1 hour) และ target gamenight-deals

10ทดสอบทั้งระบบ

10.1 สมัครสมาชิกและใส่ Wishlist (เส้นทาง B)

  1. เปิดโดเมน Amplify → เข้าสู่ระบบ → แท็บ สมัครสมาชิก ใช้อีเมลจริงของตัวเอง
  2. กดรูปหัวใจที่เกม 1–2 เกม (เลือกเกมที่ยังไม่ลดราคา) แล้วไปหน้า Collection
  3. แท็บ Wishlist กดปุ่ม เปิดแจ้งเตือนลดราคา
  4. เปิดอีเมล หาหัวข้อ AWS Notification - Subscription Confirmation กดลิงก์ Confirm subscription (ไม่เจอให้ดูใน spam)
  5. กลับมาที่เว็บกด ยืนยันแล้ว ข้อความต้องเปลี่ยนเป็น "เปิดแจ้งเตือนเกมลดราคาแล้ว"

10.2 ลดราคาเกมแล้วสั่งตรวจทันที (เส้นทาง A)

  1. หน้า Admin ของเว็บ เลือกเกมที่อยู่ใน Wishlist แล้วตั้งส่วนลด 30% → บันทึก
  2. ไม่ต้องรอ 1 ชั่วโมง: Console → Lambda gamenight-deals → แท็บ Test → Event name run-now → Event JSON {} → Test
  3. ผลลัพธ์ต้องมี "emailsSent": 1 แล้วอีเมลหัวข้อ Game Night: เกมใน Wishlist ลดราคา จะเข้ากล่องจดหมาย

#อาการสาเหตุวิธีแก้
1/api/health ได้ Internal Server ErrorHandler ไม่ตรง หรือ runtime ไม่ใช่ Node.js 22Runtime settings ตั้ง Handler index.handler, runtime Node.js 22.x
2Lambda ขึ้น AccessDeniedException ตอนอ่าน DynamoDBไม่ได้เลือก LabRoleConfiguration → Permissions → Edit → Existing role LabRole
3หน้าเว็บขึ้นแต่ไม่มีเกม, console มี CORS errorตั้ง CORS ใน API Gateway ซ้อน หรือไม่ได้ใส่ VITE_API_URL ใน Amplifyลบ CORS ใน API Gateway, ใส่ Invoke URL + /api ใน Amplify → Environment variables แล้ว Redeploy
4Amplify ขั้น Build เป็นสีแดง หรือเปิดเว็บแล้ว 404ไม่ได้ตั้ง Monorepo root เป็น frontend (วิธี zip: zip ทั้งโฟลเดอร์ dist)App settings → General settings → Edit ตั้ง root frontend แล้ว Redeploy ดู log ได้โดยคลิกขั้น Build
5ตอนเลือก repository ไม่เห็น fork ของตัวเองตอน Install ไม่ได้เลือก repo นั้นGitHub → Settings → Applications → AWS Amplify → Configure → เพิ่ม fork แล้วกลับมากด Refresh
6รีเฟรช /game/1001 แล้ว 404ยังไม่ได้ตั้ง Rewritesทำขั้น 8.3
7emailsSent: 0 ทั้งที่ลดราคาแล้วยังไม่กดยืนยันอีเมล, ส่วนลดต่ำกว่าเกณฑ์ หรือเคยแจ้งส่วนลดนี้แล้วดูค่า subscribers ในผลลัพธ์, ลดราคาให้ ≥ 10%, หรือตั้งส่วนลดใหม่ที่มากกว่าเดิม
8ปุ่มแจ้งเตือนขึ้น "ยังไม่ได้ตั้งค่า SNS topic"ไม่มี TOPIC_ARN ใน Lambda gamenight-apiเพิ่ม environment variable ตามขั้น 4
9Test seed ขึ้น Task timed out หรือ ResourceNotFoundExceptionTimeout สั้นเกิน หรือสร้างตาราง DynamoDB ไม่ครบ/ชื่อไม่ตรงตั้ง Timeout 30 วินาทีตามขั้น 4 และตรวจชื่อตารางทั้ง 6 ในขั้น 3 แล้วกด Test ใหม่

การลบระบบเมื่อใช้งานเสร็จ

ลบตามลำดับนี้ เพื่อไม่ให้เหลือตัวที่ยังเรียกอีกตัวอยู่

  1. EventBridge → Rules → เลือก gamenight-hourly → Delete
  2. Amplify → แอป gamenight-web → App settings → General settings → Delete app
  3. API Gateway → gamenight-http-api → Actions → Delete
  4. Lambda → เลือก gamenight-api และ gamenight-deals → Actions → Delete
  5. SNS → Topics → gamenight-deals → Delete (subscription ถูกลบตาม)
  6. DynamoDB → Tables → ติ๊กทั้ง 6 ตาราง gamenight-* → Delete
  7. S3 → bucket gamenight-config-… → Empty ก่อน แล้วจึง Delete
  8. GitHub → Settings → Applications → AWS Amplify → Uninstall และลบ fork ได้ถ้าไม่ใช้แล้ว (ไม่บังคับ)
  9. CloudWatch → Log groups → ลบ /aws/lambda/gamenight-api และ /aws/lambda/gamenight-deals (ไม่บังคับ)
